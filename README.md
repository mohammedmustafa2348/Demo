# IT Consulting Company Website

A modern, professional website for your IT consulting company showcasing services including software development, software testing, product customization, mobile application development, and IoT developments.

## Features

- **Modern Design**: Clean, professional theme with smooth animations
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Service Showcase**: Highlights all your IT consulting services
- **Contact Form**: Easy-to-use contact form for client inquiries
- **Smooth Navigation**: Smooth scrolling and interactive menu
- **Professional Theme**: Pleasant color scheme with professional imagery placeholders

## Services Highlighted

1. Software Development
2. Software Testing
3. Product Customization
4. Mobile Application Development
5. IoT Development
6. Cloud Solutions

## Getting Started

1. Open `index.html` in your web browser
2. No build process or installation required - it's ready to use!

## Customization

### Update Company Information

1. **Company Name**: Search for "TechConsult" in `index.html` and replace with your company name
2. **Contact Information**: Update email, phone, and address in the contact section
3. **Social Media Links**: Update the social media links in the footer

### Change Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1e40af;
    --secondary-color: #10b981;
    /* ... */
}
```

### Add Real Images

Replace the placeholder image in the about section by:
1. Adding your image to an `images` folder
2. Updating the `.image-placeholder` div in `index.html` with an `<img>` tag

### Connect Contact Form

To make the contact form functional:
1. Set up a backend service (Node.js, PHP, etc.)
2. Update the form submission handler in `script.js`
3. Add your backend endpoint URL
